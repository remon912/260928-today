# 오늘, 한 줄

> 좋은 문장을 고르고, 오늘의 마음을 기록하는 로컬 우선 웹앱입니다.

## 오늘의 작업 상태 · 2026-10-03

- 오늘의 명언 카드와 작성자별 명언 후보 선택 UI를 구현했습니다.
- 기분, 감사와 배움, 작은 약속을 날짜별로 작성하고 입력 후 약 0.7초 뒤 자동 저장합니다.
- 월간 달력에서 기록이 있는 날짜를 찾고 읽거나 해당 날짜의 기록을 이어 쓸 수 있습니다.
- 명언 카드를 PNG로 저장하고, JSON 백업을 내보내거나 가져올 수 있습니다.
- 첫 화면의 소개 문구 “마음에 닿은 한 줄, 오늘의 나를 기록해요.”를 제거했습니다. 날짜는 문장 카드 상단에 표시합니다.
- 문장 카드 모서리를 둥글게 조정하고, 키보드 포커스와 터치 영역을 보강했습니다.
- 날짜를 바꾸는 동안 입력 중인 내용이 다른 날짜에 저장되지 않도록 저장 시 날짜와 입력값을 고정합니다.

## 기술 구성

- HTML, CSS, JavaScript ES 모듈
- IndexedDB: 브라우저 안에 날짜별 기록을 저장합니다.
- Canvas 2D: 문장 카드 PNG를 만듭니다.
- `data/quotes.json`: 명언과 작성자 데이터를 제공합니다.
- 별도 빌드 도구나 서버 API는 사용하지 않습니다. ES 모듈과 JSON을 불러오기 위해 로컬 HTTP 서버로 실행해야 합니다.

## 로컬 실행

프로젝트 루트에서 실행합니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)를 엽니다. 서버를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

## 내일 이어서 할 일

- 문장 카드와 어울리는 이미지를 생성하고 카드 UI에 넣습니다. 현재 작업 세션에는 이미지 생성 도구가 연결되어 있지 않아 이미지 파일은 아직 없습니다.
- 이미지 적용 후 데스크톱과 모바일 화면에서 카드 배치와 잘림 여부를 확인합니다.
- 명언 선택, 자동 저장, 달력 조회, JSON 백업 복원, PNG 저장 흐름을 브라우저에서 확인합니다.

## 데이터와 백업

기록은 현재 브라우저 프로필의 IndexedDB에 저장되며 서버로 전송되지 않습니다. 브라우저 데이터 삭제나 다른 기기 사용 전에 설정 버튼에서 JSON 백업을 내보내 보관하세요. 백업 복원은 기록 날짜와 갱신 시각을 기준으로 처리합니다.

## 참고

- 이 프로젝트는 정적 웹앱이며, 아직 PWA 설치·오프라인 서비스 워커·클라우드 동기화는 포함하지 않습니다.
- 글꼴은 Google Fonts를 사용하므로 네트워크가 없으면 시스템 글꼴로 표시됩니다.
- 오늘은 자동화 테스트를 실행하지 않았습니다.
